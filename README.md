# Student Task Planner 📚

## Project Description
A simple functional website for students to plan daily tasks where users can add tasks, view them, mark as completed or delete.  

## Project Goal
To create a convenient digital tool to help students organize time and tasks while learning programming principles like conditions, functions, and user input handling.

## Target Audience
Students aged 12-18.  

## Problem Solved
Helps students who forget homework and cannot plan their day effectively.  

## Features
- Task addition  
- Date assignment  
- Priority levels (low/medium/high)  
- Categories (homework/study/sports/other)  
- Filtering (all/completed/pending/high priority)  
- Status changes  
- Deletion  
- LocalStorage data persistence  
- Statistics display  
- Data validation

## Usage Instructions
### How to Add Tasks
1. Enter your task in the input field.  
2. Select a due date.  
3. Assign a priority level.  
4. Click the "Add Task" button.  

### How to Mark Tasks as Completed
1. Click the checkbox next to the task.  

### How to Delete Tasks
1. Click the "Delete" button next to the task you want to remove.  

### How to Filter Tasks
1. Use the filter options to view all, completed, pending, or high priority tasks.

## Lietošanas Norādījumi  
### Kā Pievienot Uzdevumus  
1. Ievadiet savu uzdevumu ievades laukā.  
2. Izvēlieties termiņu.  
3. Piešķiriet prioritātes līmeni.  
4. Noklikšķiniet uz "Pievienot uzdevumu" pogas.  

### Kā Atzīmēt Uzdevumus kā Pabeigtus  
1. Noklikšķiniet uz ruļļa blakus uzdevumam.  

### Kā Dzēst Uzdevumus  
1. Noklikšķiniet uz "Dzēst" pogu blakus uzdevumam, ko vēlaties noņemt.  

### Kā Filtrēt Uzdevumus  
1. Izmantojiet filtrēšanas iespējas, lai skatītu visus, pabeigtos, nepabeigtos vai augstas prioritātes uzdevumus.
